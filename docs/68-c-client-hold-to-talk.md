# C 端长按语音输入与景点内容联动

## 交互

- 行程地图上的麦克风、外壳悬浮菜单中的“问”支持按住说话。
- 按下后在当前页面显示长按反馈，持续按住 300 毫秒后才启动收音，实时显示识别文字，聊天面板保持关闭；普通短按不申请麦克风权限。
- 按住至少 300 毫秒后松开，等待浏览器返回最终识别结果，再打开聊天面板并自动发送。
- 短按打开普通问答；向上移动至少 60 像素后松开取消。取消、无内容、权限失败、页面失焦或切后台不会发送问题。
- 长按会暂停路线讲解并保存断点；取消后尝试恢复。成功提问后沿用问答结束恢复讲解的机制。
- Chat 内部麦克风共用长按控制器，取消不会发送。

## 识别边界

使用 Web Speech API，启用持续识别。浏览器在停顿后结束识别时，按住期间会重新启动并保留已识别文本。松开后的最终结果等待有两秒收尾上限；仍没有结束回调时使用已获得的文本。浏览器兼容性、麦克风权限和厂商识别服务仍影响实际体验；不支持语音的浏览器可短按进入文字问答。

## 景点内容

新景点播放队列开始时，右侧内容面板默认自动打开并切换到当前播放景点，包括首站、手动切站、上一／下一节点浏览和顺序自动推进。切换景点时重新挂载内容组件，使阅读位置回到顶部。开启“锁定当前内容”后，自动播放不再切换正在阅读的内容，手动选择仍可切换。附近景点的统一入队、去重和播放控制详见 [C 端游览控制与播放序列](69-c-client-tour-controls.md)。

## 验证

- `pnpm --filter @path-seeker/h5-client type-check`
- `pnpm --filter @path-seeker/h5-client test`
- 真机验收：首次麦克风授权、连续多句与停顿、松开后自动发送、上滑取消、切后台取消、问答后讲解恢复，以及新景点内容联动。
