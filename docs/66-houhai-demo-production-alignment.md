# 后海 demo 与正式项目功能对齐

本次以 `houhai-admin-v2`、`houhai-client-v2` 的户外路线体验为参考，按提供的 `apis.json` 接口契约实现正式后台与 H5 功能。正式项目仍使用 `apps/web-admin` 的 Nuxt 4 结构和 `apps/h5-client` 的 Vue 3 / Vite 结构，共享能力放在现有 `packages/ts-shared`，未调整 workspace、包依赖或项目架构。

## 后台操作

1. 在目的地管理中打开户外目的地的「文化点」页签，维护名称、分类、位置、封面和推荐停留时长。室内目的地继续维护楼层，混合目的地同时提供楼层与文化点。
2. 在路线列表选择目的地，点击「新增路线」，切换到「文化点编排」。选择至少两个不同文化点，调整停靠顺序，填写标题、交通方式、时长和里程，创建中文源路线草稿。
3. 草稿使用原有审核和发布流程。创建后的路线需要补充讲解，再提交审核。选择外语创建时，先保存中文源路线，再创建语言版本；翻译失败可重试，不重复创建源路线。
4. 在路线列表的「更多操作 → 多语言转换」中，从中文源路线创建或复用英语、俄语、西班牙语草稿。列表支持场景与语言筛选。
5. 打开户外路线详情后，可在地图或站点列表中选择站点，双击编辑，使用上移、下移调整顺序。户外详情使用地图工作区与手机预览，室内详情继续使用原有流程图与玩法模拟器。
6. 编辑讲解站点时，可维护分段标题、正文和顺序，上传或清除段音频与站点视频。点击底部「保存」提交站点信息与分段内容。非中文版本使用匹配语言的系统语音，后台不生成中文 TTS。
7. 在「路线地图」中维护抵达说明、交通方式、停留时长和位置，绘制或生成路段，检查并确认路线。

## H5 操作

- 主入口为 `/ride`，应用根路径跳转至该入口；部署地址为 `/path-seeker/client/ride`。`/venues` 及原有室内任务流程仍可使用。
- 指定目的地入口为 `/museums/:museumId/map`。扫码链接可携带 `routeId` 与 `lang=zh|en|ru|es`，只预选路线和语言，由游客点击「开始行程」开始。
- 语言选择支持中文、英语、俄语、西班牙语，记住本机偏好。目录、路线、站点、图片、视频与讲解由正式接口提供。
- 路线预览与当前行程分别保存；返回地图浏览其他路线时，当前行程可以继续。游客可展开讲解抽屉、选择站点或导游、暂停与续播、手动完成站点或结束行程。
- 中文优先播放分段音频，加载失败时回退当前段的系统语音；外语使用匹配语言的系统语音。缺少对应语音时提示继续阅读，不替换为中文朗读。
- 定位由游客主动开启。仅接受新鲜且精度足够的定位结果，停留确认后安排附近站点；正在讲解或手动暂停时不抢占播放。讲解完成后记录完成来源并推进下一站，最后一站完成后停止播放与定位。
- 「问一问」接入正式项目现有带站点上下文的问答能力，打开时暂停讲解。

## 接口映射

后台继续通过现有 Nuxt server 代理调用后端，H5 继续通过现有 HTTP 服务直连。以下路径为后端业务路径，统一拼接已含 `/api` 的后端根地址。

| 功能 | 后端接口 |
| --- | --- |
| 文化点列表、新增、编辑、删除 | `/CulturalPlace/ListByMuseum`、`/CulturalPlace/Create`、`/CulturalPlace/Update`、`/CulturalPlace/Delete` |
| 户外草稿编排 | `/Route/BuildOutdoorDraft` |
| 语言版本 | `/Route/CreateTranslation` |
| 站点排序 | `/Gameplay/StageReorder`，顺序字段为 `orderedStageIds` |
| 分段讲解与站点视频 | `/Narration/save-segments` |
| 地图位置与路段 | 现有 `/RouteMap/*` 接口，扩展站点运营字段 |
| C 端目录与详情 | `/ClientCatalog/Catalog`、`/ClientCatalog/Route` |
| 行程开始、站点进度、放弃 | `/RouteVisit/Start`、`/RouteVisit/UpdateStop`、`/RouteVisit/Abandon` |

业务主键、路线 ID、站点 ID、附件 ID 均使用字符串。C 端目录接口按契约统一输出 WGS84；高德显示时转换为 GCJ02，后台地图取点后转换回 WGS84。`UpdateStation` 传 `coordinateSystem: 1`，`SaveSegment` 提交 WGS84 GeoJSON，不添加契约外坐标系字段。

## 环境配置

配置项已加入两个正式项目的 `.env.example`。

| 配置 | 后台 | H5 |
| --- | --- | --- |
| 后端根地址 | `NUXT_BACKEND_BASE_URL` | `VITE_API_BASE_URL` |
| 高德 JS API Key | `NUXT_PUBLIC_AMAP_KEY` | `VITE_AMAP_KEY` |
| 高德安全码 | `NUXT_PUBLIC_AMAP_SECURITY_CODE` | `VITE_AMAP_SECURITY_CODE` |
| 高德安全代理地址 | `NUXT_PUBLIC_AMAP_SECURITY_PROXY` | `VITE_AMAP_SECURITY_PROXY` |

高德加载尝试 2.1Beta，失败后回退 2.0。地图 Key 缺失或 SDK 加载失败时显示提示，路线选择、正文阅读与手动站点操作仍可用。H5 的 Vite 环境变量在构建时读取，更改后需重新构建。

## 验证记录

- H5 生产构建通过，包含 `vue-tsc` 类型检查；后台 Nuxt / Nitro 生产构建通过。
- 21 项行为与契约检查通过，覆盖大 ID、预览无自动开始副作用、显式开始、暂停保护、完成来源、最后站资源释放、结束失败重试、外语语音选择、坐标往返、GPS 质量筛选，以及新 H5 请求和后台代理的 OpenAPI 字段对照。
- 无窗口 Edge 浏览器通过真实鼠标点击验证 H5 语言选择、行程开始、讲解抽屉、返回地图和结束；验证后台文化点有序编排、三种语言版本创建、分段正文保存。未出现未捕获的浏览器异常。
- 浏览器验证使用模拟接口响应并拦截外部地图脚本，不写入真实后端。地图验证覆盖不可用时的降级；未验证真实底图和建筑效果。
- 后台全量类型检查仍受原有文件错误阻塞：`RoutePosterDialog.vue`、`useApiClient.ts`、`pages/console/maps.vue`、`server/api/guide/voice-preview.get.ts`。

## 真实环境联调

部署前需要配置后端地址与高德 Key，并验证真实文化点、已发布路线及翻译数据；在手机浏览器中检查 HTTPS 定位权限、GPS 到站判定、音频播放限制、系统语音可用性、站点视频和网络失败重试。

demo 的独立 duplex 语音服务没有对应的本次接口契约，因此本次复用正式项目已有问答链路；未声称移植独立双工语音服务或完整建筑体块效果。
