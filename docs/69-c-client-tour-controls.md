# C 端游览控制与播放序列

## 使用入口

游览页面底部播放器增加播放序列入口，数字表示待播放的景点数。展开后可以查看正在播放、待播放、已完成和已跳过的景点，并对待播放项选择“立即播放”或“跳过”。

## 播放规则

- 通过现有定位精度、停留时间和范围判定后，附近多个景点按距离从近到远追加到同一播放序列；距离相同时按路线节点顺序排列。
- 已入队景点在同一次游览内不再自动入队，包括已完成和已跳过的景点。距离变化不会重排已建立的序列。
- 正在播放时只追加新景点，当前景点播完后再继续。手动“立即播放”会切换到所选景点，并把被打断的序列项记为已跳过。
- 关闭“自动播放下一景点”不会中断当前讲解；后续符合条件的景点仍可入队，但不会自动开始下一项。手动播放依然可用。该偏好保存在当前浏览器中。
- 序列按路线和游览记录分别保存在当前浏览器中；恢复同一次游览时保留去重记录，新的游览重新建立序列。

## 内容与地图

- 默认开始新景点讲解时打开并切换内容面板。“锁定当前内容”会暂停自动切换和待播站点的自动开始；解除后继续已有队列，手动选择景点仍可切换内容。
- 地图工具栏增加路线显示开关，只控制路线线条，景点标记、实时定位和近站判定继续工作。
- 定位状态持续显示关闭、等待准确定位、开启或失败。播放器提示同步显示自动推进状态。
- 讲解播放失败时可重试当前景点，或打开内容面板阅读。

## 样式与语言

播放序列、内容面板及新增入口沿用游览页的湖绿、浅纸色、边框与圆角。交互文案覆盖中文、英语、俄语、西班牙语、法语、日语；长文案允许换行，移动端图标按钮提供对应语言的无障碍标签，动画遵循减少动态效果偏好。

## 验证与验收

- `pnpm --filter @path-seeker/h5-client type-check`
- `pnpm --filter @path-seeker/h5-client test`
- `pnpm --filter @path-seeker/h5-client build`
- 组件预览检查多语言长文案和窄屏布局。
- 真机继续验收：定位授权与弱定位、连续步行经过多个景点、暂停后恢复、锁屏或切后台后的音频行为，以及问答打断后恢复讲解。浏览器自动播放限制仍可能要求用户手动继续播放。

## 双端播放一致性（2026-10-30）

- 支付宝小程序与 H5 的内容面板均隐藏额外音频列表和跳过开关；额外音频默认随整站队列播放，忽略历史跳过偏好。
- 开启近站讲解同时开启自动接续与地图跟随；开启定位后若精度不足或定位过期，等待可用近站判定，不切到远处的下一站。
- 自动切站请求返回后重新检查提问、录音、翻译房间、前后台、自动播放偏好和内容锁定。已写入的行程进度保留，声音通过待播意图在条件恢复后启动，避免重复提交 start。
- 用户主动暂停继续保持暂停；显式选站或播放可以恢复。换站、换路线或账号变化后，旧待播意图不能启动新的内容。
- 每段媒体回调验证当前媒体实例；H5 额外隔离播放 Promise 和系统语音回调，避免同一队列中前一段的迟到事件修改后一段。
- 整站视频自然结束可完成纯视频站点；跳过和播放失败不冒充完成。单独观看视频结束、跳过或失败后恢复原队列和时间，不提前提交本站完成。
- 请求忙碌期间发生的自然结束事件暂存，忙碌解除后按当前上下文消费；失败不无限自动重试。
