# 支付宝小程序息屏收听开关

导航播放栏原“回到现在”入口替换为“息屏收听”开关，跟随车夫模式也显示。原有定位对齐方法保留，界面不再调用此入口。

默认开启，延续现有后台收听行为。选择保存在当前设备的小程序本地存储中，重新打开后仍生效。后台音频功能配置关闭时不能通过此开关绕过配置。

- 开启：息屏或切换其他 App 后允许继续播放。开启时明确提示切换其他 App 同样会继续播放。
- 关闭：应用进入后台时立即暂停本地播放器，并暂停已创建或正在创建的服务端讲解会话；房间连接按已有可恢复断线机制处理。
- 后台禁播由播放器统一检查，涵盖迟到的 Play/TimeUpdate、恢复请求、流式音频追加及会话创建完成后的源自动播放。
- 返回前台允许播放，但开关本身不发起恢复。持续讲解保留暂停状态，用户点击继续/重新连接；普通节点播放按原页面恢复规则处理。
- 改开关不会在前台打断当前播放，也不会退出房间。诊断 startup.screenOffListening 记录当前有效设置。

小程序无法可靠区分锁屏与切换 App，因此关闭后息屏也会暂停。电话或微信通话的系统音频中断另由 `my.onAudioInterruptionBegin/End` 保护：收到开始通知后暂停，收到结束通知后仍保持暂停，等用户主动重新连接或继续收听。支持范围、GitHub 证据及真机验收见 [系统音频中断处理](alipay-audio-interruption-20261113.md)。

验证命令：在 apps/mp-alipay 运行 node --test tests/*.test.cjs，运行前先执行 pnpm --filter @path-seeker/mp-alipay build。

真机验收：分别开启/关闭后测试息屏、切换微信、返回前台、创建会话过程中切后台、房间已结束后返回。需要重新发布小程序；本次开关无需后端接口变更。
