# 人工路段重新自动生成

路线地图编辑器中的“重新自动生成”会先提示目标路段、覆盖已有几何的影响，以及未保存草稿的处理。取消确认不会提交生成请求。

确认后，前端提交 `routeId`、`segmentNo` 和 `overwriteManual: true`。`routeId` 始终以字符串透传。生成成功后目标路段切换为自动来源，路线需要重新确认；规划失败时保留目标人工路段的几何与来源，前端保留未保存草稿并显示错误。

`POST /RouteMap/Generate` 的请求字段：

| 字段 | 类型 | 行为 |
| --- | --- | --- |
| `routeId` | string | 路线 ID |
| `segmentNo` | integer，可选 | 指定单段；省略时批量生成 |
| `overwriteManual` | boolean，默认 false | 允许覆盖指定路段的人工几何，必须同时提供有效的 `segmentNo` |

批量生成继续跳过人工路段。单段人工路段未带覆盖确认时返回明确错误，避免无变化却显示成功。无效路段编号或缺少编号的覆盖请求在修改地图状态前被拒绝。

前后端必须同时更新：后台 UI 与 Nuxt 代理透传覆盖参数，后端请求模型和生成服务执行覆盖规则。
