# 支付宝跟随模式：手动重连对齐车夫当前位置

点击“重新连接”时，先暂停旧媒体播放，再执行服务端已有的 `realign`，清除未完成的播放队列和旧节点播放位置，重置到站判断，然后恢复并重建媒体连接。

后续节点由车夫的新鲜位置采样及既有到站规则决定，不使用游客正在浏览的节点，也不继续补播旧队列。车夫不在可触发景点范围时等待下一次有效到站，期间仍沿用原有沿途趣事和实时讲解调度。位置失效、缺少采样或尚未满足到站条件时不能保证立即开始景点音频。已完成节点及前序到访条件仍遵守现有规则。

仅跟随车夫模式下显式点击重连使用此行为。自动网络恢复、锁屏暂停恢复及问答结束恢复保留既有续播逻辑。未开启跟随时仍按当前选中的节点手动播放。

连续点击共用一次操作；重连过程中提问、暂停、离房或房间解散会使旧操作失效，迟到响应不能重新开始播放。房间解散仍显示普通业务提示。

本次复用现有后端控制协议，不新增接口、字段或后端部署要求。需要发布新版支付宝小程序。验证包含构建、小程序回归测试，以及对现有服务端 `realign` 清理队列和重新判断到站逻辑的代码核查；真机需验证旧节点未播完时移动到新景点再手动重连，以及车夫已离开景点范围时手动重连。
