# 八语言统一

正式 H5、支付宝小程序、寻迹车夫 Android APP、管理后台的路线语言入口，以及后端路线和实时翻译协议统一为以下八种语言，顺序固定。

| 语言 | 路线语言码 | 实时翻译语言码 | 浏览器语音区域码 | MiniMax 合成语言 |
| --- | --- | --- | --- | --- |
| 中文（普通话） | `zh` | `zh-CN` | `zh-CN` | `Chinese` |
| 英语 | `en` | `en` | `en-US` | `English` |
| 俄语 | `ru` | `ru` | `ru-RU` | `Russian` |
| 西班牙语 | `es` | `es` | `es-ES` | `Spanish` |
| 法语 | `fr` | `fr` | `fr-FR` | `French` |
| 日语 | `ja` | `ja` | `ja-JP` | `Japanese` |
| 韩语 | `ko` | `ko` | `ko-KR` | `Korean` |
| 粤语 | `yue` | `yue` | `zh-HK` | `Chinese,Yue` |

## 配置和内容

- 导览语言清单：`packages/ts-shared/src/tour.ts`。H5 与管理后台直接使用；支付宝构建时将其编译到 `shared/tour.js`，配置直接引用，首次进入的语言选择页也从该配置循环渲染。选择列表支持纵向滚动，确保小屏设备可选择全部八种语言。
- 实时翻译清单：`packages/ts-shared/src/translation-room.ts`，与导览清单的语言及顺序由回归测试对齐。
- H5 和支付宝共用导览文案 `apps/h5-client/src/utils/tourMessages.ts`，房间文案与游客提问文案分别在共享包的 `translation-room-messages.ts`、`translation-room-questions.ts`。
- Android 讲话语言由 `DriverLanguages.java` 管理。APP 操作界面继续使用中文；讲话语言、房间成员语言及翻译内容按八种语言处理。
- 后端 `RouteLocales.All` 和 `TranslationTargetLanguage` 接受对应八语言；不再接受德语、独立繁体中文作为房间语言。既有枚举数值保留空位，避免重用旧语言数值。
- 路线及译文继续使用数据库 `puzzle_route`、`route_stage`、`route_stage_narration`。新增语言不会自动生成或发布已有路线的译文与音频。

## 录音和语音

导览语音提问向 `POST /ExhibitChat/transcribe` 的 multipart 表单提交 `language`，语言码采用路线语言码。旧客户端省略时沿用服务端原有默认行为。H5 在录音开始时记录语言，后续操作不会改写本次识别参数；支付宝在提交识别时读取当前语言。

粤语作为独立语言生成译文，使用自然粤语及繁体字。系统朗读只匹配 `yue`、`yue-HK`、`zh-yue` 或 `zh-HK` 音色；缺少时显示语音不可用，不使用普通话替代。普通话也不会误选粤语音色。

粤语房主输入使用现有 ASR 与 LLM 翻译链路；在豆包同传房间中，粤语收听使用识别原文的 LLM 翻译及 MiniMax 合成链路，避免把粤语当成普通话传给豆包同传。实际识别、音色和口音质量仍需在已配置的供应商及真机上验收。

## 升级

1. 在目标 PostgreSQL 数据库执行后端 `doc/102-unified-eight-languages.sql`。脚本可重复执行，补齐并启用八种语言，中文为默认语言，其他语言字典项停用；不删除既有路线或译文。
2. 部署更新后的后端 WebApi 及依赖程序集。
3. 部署 H5 与管理后台，重新构建、上传支付宝小程序并更新 Android APP。
4. 在后台为所需中文路线创建韩语、粤语草稿，完成译文、音频和审核发布后，游客端才有对应路线可选。

旧版 Android 存储的德语、独立繁体中文讲话偏好在新建房间时回落中文。H5、支付宝保存的旧房间语言通过现有归一化回落中文，粤语别名归一为 `yue`。

本次仅修改本地源码并提供迁移脚本，没有执行目标数据库脚本或部署线上服务。`houhai-client-v2`、`houhai-admin-v2` 为独立演示工程，不属于上述正式端升级范围。

## 本地验证

- H5 全量 192 项测试通过，涵盖八语言顺序、文案占位符、粤语音色匹配、韩语和粤语录音语言、问答与播放回归；生产构建和类型检查通过。
- 支付宝全量 326 项测试通过，原生工程构建通过，包含构建产物中的动态语言选择列表、韩语与粤语入口选择及重新进入时的语言恢复、空目录返回语言列表后切回中文路线、房间切换、语言缓存及 WAV 识别参数。支付宝模拟器中已实际点击验证粤语空目录的中央与顶部语言按钮均可返回八语言列表；空目录不挂载原生地图或空路线滚动容器，不显示开始行程按钮。
- 管理后台类型检查通过；路线筛选、创建与多语言转换沿用共享八语言清单。
- Android 语言配置、音频准备与房间邀请测试通过，Debug APK 构建通过。
- 后端 133 项相关测试通过，包括语言协议、路线支持清单、翻译房间、豆包适配、MiniMax 合成参数及双向翻译回归。
- 未调用真实语音供应商，未进行设备安装、真机麦克风和现场口音验收。后端构建仍输出既有依赖漏洞及版本解析警告；后台输出既有重复自动导入警告。
