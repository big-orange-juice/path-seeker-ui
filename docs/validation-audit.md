## 当前截图的实际原因

只读检查“后海黄包车长线 A+B”：第二节点郭沫若故居的目标参数为 **2400 秒**，实际音频为 **345708 毫秒，即约 5 分 45.7 秒**，正文和音频状态均为完成。创建草稿把建议参观分钟数乘 60 填成了生成目标；发布又将该生成目标按 10～600 秒拦截。音频本身没有超出该区间。

Git 历史：10～600 秒校验加入于 2026-07-14；2026-10-13 的草稿构建修改将建议参观时长填入生成目标，触发了历史规则。没有证据表明该阈值来自用户确认的业务要求。

检查时快照中，节点 **15、16、17、18、19、20、21、24、25、27** 的音频状态为失败（4）。取消错误的目标时长校验后，这些真实内容状态仍可能阻止中文发布；本轮没有改写状态或伪造音频完成。所有真实数据库检查均只读。
