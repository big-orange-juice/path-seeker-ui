# 电子明信片与段间媒体

实现覆盖 H5、支付宝小程序、B 端和 WebApi。功能名称统一为「电子明信片」。

## 用户流程

- 游览页顶部「我的」打开个人内容页。
- 只有后台开启明信片的节点才展示制作入口；游客可以看到入口，但必须注册或登录才能生成。
- 支付宝小程序额外要求服务端账号已绑定手机号。入口会打开单独的手机号授权流程，不改变普通登录的手机号可选配置。
- 手机号来自支付宝返回的签名响应，后端验签后绑定；客户端不直接提交可信手机号。
- 普通节点选择版式、可选照片和最多 160 字寄语，服务端将 HTML 模板生成 PNG。
- 终结节点可配置图生图；游客必须上传自己的照片，沿用现有 `NanoBanana2Edit` 素材生成任务，任务完成后再合成模板。
- 生成状态及结果保存到服务端，可关闭制作页面后从「我的」重新打开。
- 历史按页加载，每页 20 张；路线旅行册按 `visitId` 聚合，同一路线不同游览分别成册。尚未加载的历史可通过「加载更多」补齐。
- 图片从带身份校验的接口读取；只允许所属账号读取详情与图片。

## B 端操作

1. 管理员进入「明信片模板」，新增或编辑模板名称、类型、尺寸、版式、图片风格和启用状态。
2. 打开路线的讲解节点编辑弹窗，开启「允许在本节点制作明信片」，选择普通明信片或终点图生图，并勾选模板。
3. 保存节点并按既有审核、发布流程上线。已发布或审核中的路线遵守原有内容编辑限制。

终点按路线正式节点顺序 `StageNo → SortOrder → Id` 判断，仅最后一个节点允许配置并生成图生图。更换顺序后，生成接口会重新核对终点。

基础模板共三个：湖畔留影、旅途来信、终点 · 水彩纪念。前两个为普通模板，第三个为终点图生图模板。

模板内容支持静态 HTML/CSS，图片使用带引号的 `{{imageUrl}}`；其他内容为 `{{stageTitle}}`、`{{routeTitle}}`、`{{caption}}`、`{{date}}`。用户文字经 HTML 转义。模板禁止脚本、事件属性、外部样式和任意资源来源。

## 讲解分段与音乐、视频

沿用已有讲解分段，在节点编辑中的「段间音乐与视频」上传附件，设置「第 N 段后」。顺序为：

`第 1 段讲解 → 音乐 / 视频 → 第 2 段讲解`

插入位置必须存在后续讲解段落。配置对具有对应分段的讲解员生效；段落不足的讲解不追加到末尾。音乐和视频使用同一播放队列，视频结束后继续讲解；可跳过视频，失败时提示并继续下一段。跳过额外音频的开关同时跳过段间媒体。

切站、切语言或停止后，旧媒体回调不能推进新队列。小程序离开页面时暂停段间视频，音频仍遵守既有后台播放设置。

## 数据库与部署

后端源码位于 `CulturalTourismSystem.WebApi/Controllers/PostcardController.cs` 和 `CulturalTourismSystem.WebApi/Postcards/`。

部署到其他环境时依次执行：

1. `doc/94-electronic-postcards.sql`，建立业务表和索引。
2. `doc/94-electronic-postcards-seeds.sql`，插入基础模板，已有同 ID 模板不会被覆盖。
3. 发布 WebApi、H5、B 端和支付宝小程序，并保证任务中心正常消费素材生成任务。

当前已对本地后端配置所指向的数据库执行建表并插入基础模板；没有自动开启业务节点。

业务表：

| 表 | 内容 |
| --- | --- |
| `postcard_template` | 模板版式、生成模式、图片风格、启用状态、版本 |
| `node_experience` | 节点开关、可用模板、段间媒体与插入位置 |
| `user_postcard` | 用户、路线、节点、游览、模板快照、任务、状态与 PNG 字节 |

生产服务器需要可执行的 Chromium / Chrome / Edge，建议明确配置：

```json
{
  "Postcards": {
    "ChromiumPath": "/usr/bin/chromium"
  }
}
```

Windows 可配置 Chrome 或 Edge 的绝对路径。进程账号必须能够启动浏览器、写入临时目录和访问附件地址。渲染超时为 35 秒，不会自动关闭浏览器沙箱。

终点图生图使用现有图生图供应商、对象存储和任务中心配置。前端每 4 秒查询进行中的生成记录；用户从历史重新打开记录也会触发结果查询与模板合成。生成请求使用幂等键去重，每账号滚动 24 小时内最多 30 次，额度和落库通过数据库锁串行校验。

所有跨端主键、附件 ID、路由 ID 保持字符串。
