# 支付宝游客端：房间解散按正常业务结束处理

- 收到车夫立即解散房间通知后，停止持续讲解、位置跟随与房间恢复，清理房间恢复缓存和旧错误，显示普通提示“车夫已解散房间”。不展示音频错误、重试或复制诊断入口。
- 后台未收到解散事件，回前台重新加入时确认房间已结束，同样进入正常结束状态。
- 持续讲解创建返回 `403 / 10003 / 请先加入房间` 时，先尝试恢复原房间成员身份。确认原房间已结束才显示解散提示；房间仍可加入则等待订阅确认后恢复讲解。其他权限错误继续按错误显示。
- 正常结束的房间仍允许已接收的剩余译音播完；立即解散停止播放。加入其他房间后清除旧房间提示。
- 房间 ID、路线 ID 和行程 ID 始终以字符串透传。

验证：支付宝构建及 `server-tour-audio.test.cjs`、`room-recovery.test.cjs` 回归测试。真机仍需验收车夫主动解散、息屏后解散再回前台、成员身份过期但房间仍开放三个场景。

需要发布新的支付宝小程序版本后对线上用户生效。
