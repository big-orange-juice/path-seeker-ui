## 导出 mock 讲解词为 JSON
- 需求：把 mock 数据里的讲解词按「路线名称 + 景点名称 + 讲解词」抽成 JSON。
- mock 数据实际分两处：
  - `src/data/catalog.ts`（+ `src/data/guideNarrations.ts`）：主目录，`routes[].stopIds` → `places[].narration`（章节式）与 `places[].guideNarrations`（多位导游版本）。
  - `src/ride/catalog.ts`：黄包车场景脚本，zh/en/ru/es 四语，运行期由 `buildRideCatalog(locale)` 生成，story 文本内联在该文件、`names/stories/buildings` 未导出。
- 产出：`mock-narrations.json`（项目根；84KB）。结构：`{generatedAt, source, routes[], places[], rideSceneScripts[]}`。
  - `routes[]` 含 9 条路线、34 个基础讲解章节、24 个多导游版本；`places[]` 为景点索引（含 routeIds 反查）；`rideSceneScripts[]` 为 3 条骑行路线的四语脚本。
- 抽取脚本：`scripts/extract-narrations.ts`，用 `node_modules/.bin/esbuild --bundle --platform=node --format=esm` 打包后以 node 运行（项目无 tsx，这是读 TS mock 数据的可用路径）。
