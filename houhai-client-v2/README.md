# 后海慢游 · 黄包车讲解 Demo

## 2026-09-22 当前版本

当前入口已按本次确认的修改意见调整为：选择语言 → 地图选择路线 → 点击「开始行程」→ 沿途讲解。支持中文、英语、俄语、西班牙语。导游及讲解特色随路线确定，首版不开放语音问答，不做 AR、数字孪生或播放进度同步。

### 启动与验证

在本目录运行（Node.js 22.6+、npm 10+）：

```powershell
npm ci
npm run dev
npm test
npm run build
```

开发地址为 http://127.0.0.1:5188/ 。支持扫码链接参数，例如：

```text
http://127.0.0.1:5188/?routeId=2096000000000000003&lang=ru
```

`routeId` 始终作为字符串处理；`lang` 支持 `zh/en/ru/es`。有效路线自动预选并滚动到对应卡片，用户仍需点击「开始行程」。未知路线显示提示并允许重新选择，不自动开始播放或请求定位。语言偏好保存在本地；当前行程仅在页面生命周期内保留，刷新后重新选择并开始。

### 首版体验

- 地图页保留路线搜索、横向路线卡片、导游特色和中央开始按钮。场馆切换、目的地目录、收藏、足迹、问答不再出现在这条主流程。
- 行程页以整屏路线地图为主：左下角悬浮条常驻当前景点与播放/暂停，点它可反复开合右侧讲解抽屉；直接点选地图站点或途经点列表同样会弹出对应讲解。讲解抽屉不带遮罩，地图保持可见、可拖拽。途经点以右下角悬浮标签显示数量，点开从右侧滑出站点列表，地图上保留带序号的悬浮标记。返回地图、预览其他路线不会切断当前讲解；开始另一条路线会结束旧行程。结束行程会释放定位和语音。
- 近站提示不打断当前语音；当前段结束后接播最新有效站点。闲置时自动播放，用户主动暂停后保持暂停。连续经过多站时不积压旧内容。
- 定位采用 1 秒刷新、100 米触发半径、至少 1.5 秒停留确认，精度超过 65 米或超过 15 秒的定位不触发自动讲解；待播地点离开 180 米范围后不再接播。这些是 Demo 初始参数，见 `src/ride/progression.ts`，须经乘车实测校准。
- 定位不可用时可手动点选途经点；地图不可用时仍可选路线和阅读、播放讲解。
- 五张实景图保存在 `public/ride-photos/`，总计约 1.2 MB，出处及许可见其中的 `ATTRIBUTION.md`。视频播放器已支持 `stop.video` 配置，当前没有提供视频素材，因此不显示空的视频按钮。

## 可体验内容

- **导航工具**：全屏游览时右侧提供缩放和视角回正图标，底部提供当前地点故事的播放、暂停、继续和停止。复用页面讲解状态，退出导航不打断讲解；手动缩放在定位更新时保留。

- **左侧详情入口**：地图详情默认收起为左下角的地点按钮，点击恢复摘要卡；摘要和详情标题旁的左箭头可再次收起，Escape 也可收起。手机展开卡片为右侧语音、聊天按钮预留空间，收起界面不会停止讲解。

- **黄包车慢游**：北京后海真实地图、五个真实文化地点、搜索与分类、缩放与全览、点位和侧栏联动。
- **五个地点与多导游讲解**：银锭桥、烟袋斜街、广化寺、宋庆龄故居、恭王府；每个地点提供历史与亲子两个版本，恭王府另有古建园林版本。选择导游会同步切换讲解标题、时长、全文和朗读内容，并停止上一版本的播放。
- **三条运营预设路线**：后海慢游·湖与胡同、水岸寻静·古寺与故居、京味拾光·街巷与王府。点位与路线多对多关联，点击地点立即显示关联路线并在地图高亮其中一条，点击其他关联路线可以切换。
- **游览路线内的层级菜单**：底部面板始终保留“地点故事 / 游览路线”页签，进入“游览路线”先展示当前目的地的全部路线，不受当前文化地点限制。路线卡片展示主题、时长、里程及停靠顺序；选中后在同一页签内进入详情并更新地图高亮，通过页签下方“全部路线 › 当前路线”返回目录。地点讲解内仍保留“经过这里的路线”。
- **场馆探索**：选择场馆后，以双列瀑布流展示该馆的多条路线。文化探索馆内置六条路线，支持主题筛选；卡片展示封面插画、站数、标题、导游与时长。进入路线后可以查看站序、展品讲解并逐站完成，每条路线独立记录进度。
- **上级地点菜单**：黄包车与场馆各自拥有地点目录；当前可用北京后海与文化探索馆，同时预留上海朱家角古镇、故宫博物院、上海博物馆等“筹备中”入口。新增地点只需向 `destinations`、`places` 和 `routes` 目录补数据即可。
- **完整游览**：查看路线 → 开启体验 → 按顺序完成站点 → 足迹回看；支持场景切换、收藏、刷新后的进度恢复，两种场景互不覆盖。
- **问一问助手**：底部“问”入口打开与外部一致的浅色助手面板，使用纸白、浅灰绿与深青色；支持文字 / 语音模式、快捷提问、浏览器朗读、路线和预约提示。当前使用本地 mock 回复，不调用生产接口。
- **地图优先的响应式界面**：户外地图铺满顶部场景栏与底部导航之间的区域。搜索、分类与地点快捷入口浮在地图上方，底部详情支持摘要、半展开、展开三个停靠位置。点击“听这里的故事”或“游览路线”进入半展开；拖动顶部把手调整高度，也可点击把手或使用上下方向键切换，按 Escape 收起。地图避让参考停靠位置，拖动过程中不逐帧调整地图；支持系统减少动态效果设置，地图来源署名保持可见。
- **集中式讲解面板**：底部面板使用横向导游选择条，紧接着展示当前讲解和播放按钮。完整讲解、经过此地的路线按需展开，减少多层标题和纵向卡片带来的滚动；面板收起后保留当前导游选择与阅读内容。
- **地图快捷操作**：缩放按钮下方提供音符与聊天两个圆形按钮。音符与讲解卡片共用播放状态，支持开始、暂停和继续；播放时旋转，暂停及结束时静止。收起面板或切换路线页签不打断讲解，切换地点或导游则停止旧讲解。聊天按钮打开现有“问”面板，朗读聊天回复时停止地点讲解；仅打开或关闭聊天不打断地点讲解。系统减少动态效果设置下，以按钮颜色和状态提示区分播放状态。
- **实时定位**：地图工具栏提供定位按钮。用户主动开启并授权后，每 1 秒重新请求一次高精度位置，在地图上更新当前位置和精度范围；首次定位自动聚焦，之后只移动定位点，不抢夺用户手动浏览地图的视野。再次点击定位按钮可回到当前位置，状态条显示最后更新时间并支持停止。拒绝权限、超时或设备无法定位时显示明确提示和重试入口。定位只保存在页面内，不写入本地存储或 mock 数据。

## 地图配置

游览模式采用高德 JS API 2.0 的 3D 楼块、19 级近景、65° 俯仰角、路线方向箭头。按路线方位角的反方向旋转地图，使前方道路朝屏幕上方；使用 `containerToLngLat` 与 `setCenter` 校正透视投影，将位置标放在屏幕高度的 75% 处。进入全屏、尺寸变化和回到游览视角时重新应用镜头。附近没有定位时显示路线起点预览，顶部显示直线距离，不推算步行到达时间。

实现依据：[高德 JS API 2.0 官方参考](https://a.amap.com/jsapi/static/doc/20230922/index.html) 中的 `MapOptions`、`setRotation`、`setPitch`、`containerToLngLat`、`setCenter`、`PolylineOptions.showDir`。楼块细节取决于高德在该区域的数据覆盖；此 Web 游览视角不等同于高德原生 App 的导航引擎。

地图统一使用高德地图 JS API 2.0，需要联网加载 SDK，并配置 Web 端 JS API Key 与安全配置。地图读取失败会显示提示和重试按钮，讲解、路线和收藏仍可使用；不再提供 OSM / Leaflet 兜底。

复制 `.env.example` 为 `.env.local` 后可修改配置，修改后重启开发服务。不要提交凭据。

| 配置项 | 默认值 / 说明 |
| --- | --- |
| `VITE_AMAP_KEY` | 高德 Web 端 JS API Key；前端公开标识，需设置域名白名单 |
| `VITE_AMAP_SECURITY_CODE` | 本地演示可用的 `securityJsCode`；会进入客户端构建产物，不建议生产使用 |
| `VITE_AMAP_SECURITY_PROXY` | 高德官方安全代理 `serviceHost` 地址，例如 `https://your-domain.example/_AMapService` |

地图中心、缩放级别及署名位于 `src/config/map.ts`。如更换瓦片服务商，请同步更新 `attribution`，并遵守其授权、配额及署名规则。OSM 公共瓦片适合轻量方案演示，正式上线请选用适用的商用地图服务，不要批量下载或离线抓取公共瓦片。

### 接入高德

1. 在高德开放平台创建 Web 端 JS API Key，配置本地 / 部署域名白名单。
2. 按高德 JS API 安全密钥文档部署安全代理，服务端保管安全密钥，通过 `serviceHost` 代理相关服务。此纯前端项目不包含该代理服务。
3. 本地演示在 `.env.local` 设置 `VITE_AMAP_KEY` 与 `VITE_AMAP_SECURITY_CODE`；生产环境设置 `VITE_AMAP_KEY` 与 `VITE_AMAP_SECURITY_PROXY`，并让安全代理在服务端保管安全密钥。
4. 重启项目，验证地图。未配置或 SDK 加载失败时页面明确提示，可手动切回 OSM。

所有 `VITE_*` 变量都会进入客户端构建产物，因此 `VITE_AMAP_SECURITY_CODE` 只用于本地演示。生产环境应改用 `VITE_AMAP_SECURITY_PROXY`，由服务端保管安全密钥。本项目的数据统一保存 WGS84 经纬度，绘图前统一转换为 GCJ-02，避免混用坐标系。

## 地理与内容说明

地图是真实在线底图；五个点位坐标已参照 OpenStreetMap 地名搜索结果校对，取展示中心点，未经过现场测绘或出入口核验。路线折线、里程、时长是策划演示数据，不是地图路网计算结果，也不是已批准的黄包车运营线路。路线同时含车辆接驳和下车步行，古寺、商业街、故居和王府的车辆通行与开放情况应由运营方核实后再发布。

坐标核对来源：银锭桥 `OpenStreetMap way/816148132`、烟袋斜街 `way/42676210`、广化寺 `way/929752805`；宋庆龄故居与恭王府使用 OpenStreetMap 对应同名博物馆搜索结果的地图中心。原始经纬度统一为 WGS84。

讲解为原创演示稿，历史细节上线前应经内容审核；场馆展品不对应真实馆藏编号。地点图片是本地 SVG 主题插画，不是景点照片。语音使用浏览器 SpeechSynthesis，依赖浏览器及操作系统中文语音能力，无法播放时可继续阅读完整文字；未接入付费 TTS 或真实讲解录音。

高德地图已作为唯一地图引擎，支持路线展示、实时定位和 3D 游览视角。项目没有真实预约、购票、黄包车调度、后台编辑，也没有转向播报、偏航重算等实时导航服务。
