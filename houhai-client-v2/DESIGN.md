# 后海慢游 · C 端 V2 方案

> 2026-09-22：此文保留探索版的历史方案。当前产品入口已改为四语黄包车讲解，最终范围和文件结构以 README「2026-09-22 当前版本」为准。场馆、收藏、问答和全屏导航不是当前首版的用户入口。

## 产品目标

面向正在北京什刹海游览的游客，先在真实地图上发现文化地点，再听讲解、查看运营方编排的路线并开启游览。同一个 C 端同时容纳原有场馆路线模式与黄包车户外路线模式，两种模式都有地点上级菜单，可以继续添加古镇、场馆和对应路线。此文件夹是独立可运行的方案，不依赖原有应用或修改其代码。

## 视觉方案

- 色彩：湖水深青 `#183e43`、浅湖蓝 `#dcebee`、纸白 `#f8faf9`、石灰 `#e5eae7`、银杏黄 `#e5b957`、朱砂 `#b95646`。
- 字体：标题用本机宋体 / Noto Serif SC，正文用微软雅黑 / PingFang SC，地图数据用等宽字体。
- 布局：户外地图填满导航之间的可用空间，搜索与地点入口浮在上方，地点摘要和详情浮在下方。桌面浮层靠左，手机浮层靠底部并横向铺开；统一纸白圆角面板内使用紧凑分段页签、横向导游选择条与集中播放器，完整讲解和关联路线按需展开。场馆继续使用路线瀑布流。
- 记忆点：地图上带序号的深青文化地点标记，与路线停靠站次一一对应；“湖岸慢游”的车票式行程卡承载距离、时长与启程入口。
- 取舍：地图是主要视觉内容，不用占屏宣传图；地点配图为本地主题插画，明确不冒充实景照片。

## 两种路线的行为

黄包车：真实底图 → 文化地点 → 讲解与关联路线 → 高亮预设路线 → 开始体验 → 逐站游览 → 纪念足迹。

路线层级位于底部面板的“游览路线”页签内：全部路线目录 → 单条路线详情 → 开始体验。“地点故事 / 游览路线”两个页签始终保留；路线目录使用当前目的地的完整路线集合，不按选中地点过滤。选中路线更新地图，页签下方显示“全部路线 › 当前路线”，点击“全部路线”返回目录。地图上不另设目录入口，摘要中的“游览路线”打开对应页签，层级切换保持面板高度。OutdoorExplorer 管理显示状态，ExplorerDetails 在页签内组合目录、层级导航与详情，ExplorerShell 传入数据并转发选择操作。

场馆：上级场馆菜单 → 当前场馆的路线瀑布流 → 选择路线 → 查看站序与展品讲解 → 开始体验 → 逐站完成。桌面端路线列表与详情并排；手机端进入详情后可返回路线展厅，保留筛选。

地图地点支持多个导游讲解版本。默认展示第一位导游的版本；用户切换导游后更新标题、时长与章节正文，并停止正在播放或暂停的旧音频。切换地点时恢复该地点默认导游；没有多版本数据的展品兼容原有讲解。

地图右侧音符按钮与讲解卡片同步开始、暂停和继续播放；切换详情页签及收起面板不销毁播放器。播放结束或失败会同步停止旋转，失败显示提示。聊天快捷入口打开与底部“问”相同的面板，仅朗读聊天回复时停止地点讲解，避免状态失配或叠音；关闭聊天只清理聊天自己的语音。

实时定位必须由用户点击地图定位按钮启动。首次成功定位后地图聚焦当前位置，后续每秒更新定位点与精度范围，但不持续重置地图视野；用户可继续缩放或拖动地图，并随时点击定位按钮重新聚焦。状态条显示最后更新时间并提供停止操作。定位坐标仅交给当前地图适配器绘制：OSM 使用 WGS84，高德适配器绘制前转换为 GCJ-02；不持久化、不上传，也不用于伪造到访判定。

户外详情分为三个高度：摘要保留地点和两个主要入口；半展开优先呈现导游选择及播放；展开提供完整阅读空间。把手支持拖动、点击和键盘上下方向键，收起按钮或 Escape 返回摘要。详情内部滚动与把手拖动分开，避免阅读时意外移动面板；收起不卸载详情内容。拖动直接跟随指针，释放后平滑停靠，地图边距只随停靠位置更新；系统开启减少动态效果时关闭面板过渡。手机完整展开时隐藏顶部搜索浮层，减少遮挡。

地点和路线为多对多关系。点击地点会自动选中包含它的预设路线，并显示所有相关路线；当前路线已包含该地点时保留当前选择。路线来自 mock 运营数据，不根据当前位置自动生成。地图折线为策划示意，实际路权、车辆通行与停靠位置需现场核验。

## 演示边界

文化地点真实存在；坐标为 WGS84 近似展示位置，不作为测绘或入口定位成果。讲解为原创演示文本，历史细节应经内容审核。场馆展品是独立示例。收藏、路线进度与完成记录保存在此项目独立的浏览器存储键中。无需登录、后端、生产凭据；不调用现有生产业务接口。
