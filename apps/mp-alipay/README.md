# Path Seeker 支付宝原生小程序

AppID：`2021007109685406`。

首次发布与后续更新请参照 [发布流程](./RELEASE.md)，包含平台配置、体验版真机验收、提审、上架及版本回退步骤。

使用支付宝原生 `App`、`Page`、AXML、ACSS 和 `my.*` API。运行包不依赖 Vue、uni-app、浏览器 DOM 或 WebView。H5 的页面和交互重新实现；坐标转换、景点范围判定与导览语言文案复用现有纯逻辑模块，并在构建时编译到小程序目录。

## 开发与导入

在仓库根目录执行：

```powershell
pnpm install
pnpm build:mp-alipay
pnpm test:mp-alipay
```

持续开发时运行：

```powershell
pnpm dev:mp-alipay
```

构建监听 `src`、共享地理模块和 H5 的 `tourMessages.ts`。修改后会重新生成 `dist`。

1. 安装支付宝官方小程序开发者工具，使用有此 AppID 开发权限的支付宝账号登录。
2. 导入本仓库的 `apps/mp-alipay`，选择支付宝小程序。根目录的 `mini.project.json` 已关联 AppID，并将小程序目录指向 `dist`。
3. 如果工具版本要求直接导入小程序源目录，导入 `apps/mp-alipay/dist`；构建会在其中生成独立的 `mini.project.json`。
4. 编译后进入“漫游”，检查路线目录、地图和页面跳转，再使用真机预览检查音频、定位和录音。

请编辑 `src` 中的源码。`dist` 是可导入的生成目录，已被仓库忽略，重新构建会覆盖同名文件。构建使用 TypeScript，小程序单独锁定 `marked@4.3.0` 生成 Markdown 解析模块，避免 H5 新版库中的命名捕获组和 Unicode 属性转义超出支付宝 SDK 2.x 的支持范围；先在仓库根目录安装工作区依赖。有现成依赖时也可直接运行：

```powershell
node apps/mp-alipay/scripts/build.cjs
node --test apps/mp-alipay/tests/*.test.cjs
```

`build` / `validate` 检查 JS/TS 转译、JSON、页面完整性、模块依赖、浏览器 API、正则兼容性、AXML 表达式、标签与事件处理函数。AXML 的 `{{…}}` 内直接使用 `&&` 等运算符，不使用 `&amp;&amp;` 等 HTML 实体。这些检查不等同于支付宝开发者工具的原生编译，也不提供 JS 语义类型检查。

## 功能与 H5 对应关系

### 地图 3D 验证边界

导航请求原生地图的建筑图层、50° 倾角和 18 级缩放，路线总览仍使用俯视视野。镜头在视图提交后更新，并在地图初始化完成后重新应用中心和缩放。`[tour-map] engine` 的 `is3d` 仅表示引擎模式；`[tour-map] camera` 才记录请求和实际读取的倾角。实际倾角也不能证明当前区域有建筑模型，必须检查画面。

2026-10-17 核对本机支付宝开发者工具随附 `modules.asar` 中的 `@ali/lyra-integration-ide/dist/ide/runtime.bundle.js`：`drawMap` 创建 `viewMode: '3D'`，但不读取 `skew`、不设置 pitch；`updateComponents` 不处理 `enableBuilding`，`tiltGesturesEnabled` 是空实现；`getMapProperties` 根据 `getViewMode_()` 返回 `is3d`。因此原版模拟器可报告支持 3D，却不应用小程序请求的俯仰角。AppX 属性表包含 `enable-building`、`enable-overlooking`、`skew`，这些原生属性继续供客户端使用。

本机模拟器 3D 补丁已因点击交互异常撤回，脚本 `scripts/simulator-map-3d.cjs` 已禁用生成和安装，仅保留恢复入口。原文件备份为安装目录下的 `modules.asar.path-seeker-3d-backup`。恢复需要管理员权限，恢复后必须完全退出并重启开发者工具；单元测试不代表模拟器交互通过验收。

```powershell
node apps/mp-alipay/scripts/simulator-map-3d.cjs restore 'C:/Program Files/小程序开发者工具/resources/app/modules.asar'
```

真机预览时进入行程并点击左侧 3D，检查镜头是否聚焦当前站点、`actualSkew` 是否大于 0，以及当前区域是否显示建筑侧面。若实际倾角为 0，仍属客户端未应用镜头；若倾角正常但没有建筑，需要继续核对客户端建筑图层支持及地图覆盖。构建和单元测试不证明真机建筑已渲染。若最终要求与 H5 完全一致，需要另行接入 H5 WebView 导览，并完成业务域名、鉴权和定位/音频交互配置。

移植范围依据 `apps/h5-client/src/router/index.ts` 当前启用的路由。

| H5 入口 | 原生页面 | 行为 |
| --- | --- | --- |
| `/ride`、`/museums/:museumId/map` | `pages/tour/index` | 目的地、路线、讲解语言、导游、地图、站点图文与视频、行程与播放 |
| `/shell/ask` | `pages/chat/index` | 文字问答、录音转写、语音回复、资料来源、位置、建议问题、对话历史 |
| `/auth` | `pages/auth/index` | 支付宝手动授权登录、现有寻迹账号登录/注册、游客浏览 |
| `/shell/me` | `pages/me/index` | 个人资料、讲解语言、问答音色、退出登录、清除本机记录 |
| `/shell/playing`、`/shell/archive` | `pages/records/index` | 本机户外漫游、服务端进行中/已完成探索、足迹 |
| 权限与使用说明 | `pages/privacy/index` | 定位、麦克风与数据使用说明、权限设置入口 |

H5 已下线的展馆浏览与室内谜题页面没有启用对应的原生入口。

导览页与 H5 保持三层结构：首次打开先显示语言选择层；选择语言后进入路线总览层，地图作为背景、路线卡片和“开始行程”作为主操作；正式开始后进入导航层，地图全屏展示，底部保留播放控制，站点正文、图片、视频、章节、讲解员和完成操作通过内容侧栏查看。导航层可收起内容回到地图，也可打开播放序列侧栏；返回总览不会结束服务端行程，结束行程才会清除进行中的导航状态。

导览支持：

- 中文、英语、俄语、西班牙语、法语、日语讲解；导览主要控制文案复用 H5 翻译，账号和问答界面使用中文。
- 原生地图显示路线、站点、目的地边界、景点多边形/圆形范围；支持位置跟随、路线显隐、缩放和地图全屏。隐藏路线仍保留范围轮廓。
- 正式行程中点击地图标记或站点列表会进入该站并播放；上一站/下一站只浏览并播放，不写行程进度。已完成站点重听不重复记账。
- 播放顺序为前置额外音频 → 讲解章节 → 后置额外音频。支持暂停、继续、拖动、前后 15 秒、重播、单独播放额外音频、跳过额外音频。
- 额外音频出错时提示并跳过；主讲解缺失或失败时保留正文和手动完成入口，不自动标记完成。
- 正式行程讲解完成后发送 `completionSource=2`；手动完成发送 `completionSource=1`。仅额外音频结束不会完成本站。
- 开启定位后，稳定接近的景点按距离入队；播放期间只追加，当前站结束后再接续。支持立即播放、跳过待播放站点、固定当前内容、关闭自动播放。
- 手动浏览时暂缓自动切换。显式进入站点后恢复接续；播放队列按账号、路线与行程保存，恢复时对照服务端已完成站点。
- 播放断点校验账号、行程、路线、站点、导游、语言和额外音频设置；最多恢复六小时内的匹配断点。
- 从导览进入“问一问”时携带当前路线、站点、导游、章节和播放时间；支持页内浮层及展开，问答结束/关闭后恢复被中断的讲解，用户主动暂停的音频不自动恢复。
- 导览页按住提问，松手后立即切到问答页显示识别状态，识别成功自动发送；上滑取消不提交。

问答支持增量文字与按句接续音频、当前句字幕及播放进度、安全 Markdown 富文本、失败问题重试、历史与建议问题。朗读时按住说话会停止当前回答并转为录音；支持设备上可主动开启“说话打断”。本次六项业务补齐和实机验收步骤见 [H5 业务对齐验收单](../../docs/94-alipay-h5-business-parity.md)。

首次打开会先创建游客身份，并直接进入授权页面；用户可以同意隐私说明后点击“支付宝授权登录”，也可以选择“先以游客身份漫游”继续使用小程序。游客选择继续后不会重复跳转授权页。授权完成后使用 `my.getAuthCode` 的 `auth_user` 授权码请求 `/AppUser/MiniProgramLogin`；不申请手机号，不读取支付宝昵称或头像。首次授权可原地升级游客账号，已有关联身份时登录关联账号。仍支持寻迹账号密码登录。授权后进入语言选择和路线总览，并优先选中本机记住的已发布路线，否则选中当前语言的首条路线。检测到同一路线有进行中的行程时，恢复导航地图和播放状态。服务端配置、微信兼容接口和 DDL 见 [小程序身份接入说明](../../docs/93-mini-program-auth-integration.md)，上线前需执行数据库脚本并部署新接口。

小程序页面参数支持：

```text
pages/tour/index?routeId=字符串路线ID&destinationId=字符串目的地ID&lang=zh
```

`routeId`、`destinationId` 与所有业务主键始终按字符串处理。地图 marker ID 使用站点下标加一，仅作为原生地图事件索引。

## 服务与开放平台配置

`src/config.js` 默认配置：

```text
API: https://www.omahaaigc.com/path-seeker/api
默认问答音色: male-qn-qingse
```

授权页额外登录入口通过 `src/config.js` 的 `authOptions` 配置：`guestLogin` 控制游客登录，`passwordLogin` 控制账号密码登录及注册。两项默认均为 `false`，默认仅显示支付宝授权登录；将对应值改为 `true` 并重新构建即可开启。此配置仅控制授权页入口，不关闭后台游客会话的创建与恢复。

部署环境切换时修改 `apiBase` 并重新构建。AppID 在根目录 `mini.project.json` 和 `src/config.js` 中保持一致。

在 AppID 对应的开放平台后台完成：

1. 将 `https://www.omahaaigc.com` 加入请求域名配置。还需配置接口实际返回的图片、视频、讲解音频所使用的 HTTPS 域名；如媒体发生重定向，目标域名也需要满足平台限制。
2. 按当前平台控制台要求配置定位、录音相关能力及权限用途，完成隐私政策、主体与运营联系信息。小程序中的说明页用于解释操作，运营方的正式隐私政策仍需在平台提供。
3. 使用 AppID 的开发成员进行真机预览。正式访问需要后端证书有效、域名配置生效，以及发布了对应语言的路线内容。

主要接口复用 H5：

| 模块 | 接口 |
| --- | --- |
| 账号 | `AppUser/GuestLogin`、`Login`、`Register`、`RefreshToken`、`Profile`、`UpdateProfile` |
| 目录 | `ClientCatalog/Catalog`、`ClientCatalog/Route` |
| 行程 | `RouteVisit/Active`、`Start`、`UpdateStop`、`Abandon` |
| 问答 | `ExhibitChat/sessions`、`history`、`archive`、`send-with-audio`、`transcribe` |
| 历史 | `Gameplay/MyRouteHistory`、`MyCompletedRoutes`、`MyFootprints` |

HTTP 使用支付宝 `headers`、响应 `status` 与统一业务信封。明确的鉴权失败最多共享刷新一次并重放；写请求发生网络超时不会自动重放。退出或切换账号后，迟到的请求不能覆盖新账号状态。

## 平台差异

- **问答接收方式**：请求启用分块并探测 `onChunkReceived`。实际收到分块时增量解析 UTF-8/SSE、更新文字，每句音频收齐后写临时文件并接续播放；完整响应不重复播放已消费事件。客户端不提供分块或中间链路缓冲时，自动按完整响应处理。是否能稳定边生成边播放需要真机确认，当前没有引入 WebSocket。单次问答/转写超时为 120 秒；取消后服务端可能已保存答案，可通过历史查看。
- **录音**：使用 `my.getRecorderManager()` 生成单声道 16 kHz WAV，导览页和问答页都支持按住录音、上滑取消；松开后转写，识别到内容会自动提交问答。WAV 需要支付宝 **10.6.36 或以上**。临时文件使用 `audio/wav` 的 multipart 上传，保留 WAV 二进制数据；该上传链路需要真机联调确认。模拟器不能代替录音验收。
- **说话打断**：默认关闭，仅在提供实时录音帧回调的设备显示开关。开启后使用本机 PCM 能量检测，不上传检测帧；结束后清理原生接口产生的临时文件。PCM 帧格式、录放并行与外放回声效果需要实测，不支持时使用按住说话打断。
- **正文朗读回退**：本次按“已上架路线一定有音频”交付，不移植 H5 浏览器语音合成兜底。保留音频加载失败后的正文和手动完成入口。
- **前后台**：离开导览页停止定位并暂停讲解，回到前台时按离开前的播放状态恢复匹配断点；离开问答页停止录音、取消等待、停止问答音频并清理临时文件。不启用后台持续定位或后台音频能力。
- **坐标**：原生地图与定位使用 GCJ-02；地理范围判定转换为 WGS84 后复用共享逻辑。地图显示也会按后端坐标标识转换。
- **历史范围**：后端目前没有户外 `RouteVisit` 历史列表接口。本机漫游记录按账号保存最多 100 条；服务端活动行程可在对应路线恢复。`Gameplay` 历史来自已有探索接口，不代表完整的跨设备户外历史。

## 验收

自动测试覆盖登录续期与账号竞争、字符串长 ID、流式 UTF-8/SSE、按句音频、旧请求隔离、录音交接与自动发送、人声检测、浮层生命周期、浏览与行程完成隔离、断点恢复、地图跟随、语言切换、附近景点排队和各类历史返回。测试使用隔离的 `my.*` 模拟环境，不证明原生客户端或线上后端已经联调成功。

开发者工具与真机按以下顺序验收：

1. 编译六个页面，检查冷启动游客目录、空数据、网络错误重试与三个原生 Tab。
2. 搜索路线、切换目的地/讲解语言/导游，检查多语言路线、地图标记与范围、站点正文、图片和视频。
3. 正式行程中点击地图/列表站点，确认开始事件正确；上一站/下一站浏览并播放时不写 `UpdateStop`，检查前置/章节/后置音频顺序以及自动、手动完成来源。
4. 在不同音频段暂停、拖动、切到问答并返回、切到后台、退出重新进入，检查断点位置和重复额外音频行为。
5. 真机开启定位，检查精度不足、拒绝授权、单点接近、多点排队、播放期间新景点入队、固定当前内容与跳过。
6. 创建对话、查看历史、删除对话、文字问答、语音回复、来源图片和位置导航；停止等待后再看历史。
7. 真机录音至少一秒，检查松手立即跳转、WAV 转写后自动提问；测试上滑取消、快速松手、拒绝麦克风权限、离开页面与朗读期间打断。另按验收单记录分块接收、首句播放时机和外放回声效果。
8. 注册/登录、资料修改、游客与正式账号切换，确认历史、断点、音色及排队信息按账号隔离；清除本机记录后服务端进度仍可恢复。
