# Path Seeker 支付宝原生小程序

AppID：`2021007110628321`。

首次发布与后续更新请参照 [发布流程](./RELEASE.md)，包含平台配置、体验版真机验收、提审、上架及版本回退步骤。

使用支付宝原生 `App`、`Page`、AXML、ACSS 和 `my.*` API。运行包不依赖 Vue、uni-app、浏览器 DOM 或 WebView。H5 的页面和交互重新实现；坐标转换、景点范围判定与导览语言文案复用现有纯逻辑模块，并在构建时编译到小程序目录。

## 开发与导入

在仓库根目录执行：

```powershell
pnpm install
pnpm build:mp-alipay
pnpm test:mp-alipay
```

持续开发时运行：

```powershell
pnpm dev:mp-alipay
```

构建监听 `src`、共享地理模块和 H5 的 `tourMessages.ts`。修改后会重新生成 `dist`。

1. 安装支付宝官方小程序开发者工具，使用有此 AppID 开发权限的支付宝账号登录。
2. 导入本仓库的 `apps/mp-alipay`，选择支付宝小程序。根目录的 `mini.project.json` 已关联 AppID，并将小程序目录指向 `dist`。
3. 如果工具版本要求直接导入小程序源目录，导入 `apps/mp-alipay/dist`；构建会在其中生成独立的 `mini.project.json`。
4. 编译后进入“漫游”，检查路线目录、地图和页面跳转，再使用真机预览检查音频、定位和录音。

请编辑 `src` 中的源码。`dist` 是可导入的生成目录，已被仓库忽略，重新构建会覆盖同名文件。构建使用 TypeScript，小程序单独锁定 `marked@4.3.0` 生成 Markdown 解析模块，避免 H5 新版库中的命名捕获组和 Unicode 属性转义超出支付宝 SDK 2.x 的支持范围；先在仓库根目录安装工作区依赖。有现成依赖时也可直接运行：

```powershell
node apps/mp-alipay/scripts/build.cjs
node --test apps/mp-alipay/tests/*.test.cjs
```

`build` / `validate` 检查 JS/TS 转译、JSON、页面完整性、模块依赖、浏览器 API、正则兼容性、AXML 表达式、标签与事件处理函数。AXML 的 `{{…}}` 内直接使用 `&&` 等运算符，不使用 `&amp;&amp;` 等 HTML 实体。这些检查不等同于支付宝开发者工具的原生编译，也不提供 JS 语义类型检查。

## 功能与 H5 对应关系

### 地图 3D 验证边界

导航请求原生地图的建筑图层、50° 倾角和 18 级缩放，路线总览仍使用俯视视野。镜头在视图提交后更新，并在地图初始化完成后重新应用中心和缩放。`[tour-map] engine` 的 `is3d` 仅表示引擎模式；`[tour-map] camera` 才记录请求和实际读取的倾角。实际倾角也不能证明当前区域有建筑模型，必须检查画面。

2026-10-17 核对本机支付宝开发者工具随附 `modules.asar` 中的 `@ali/lyra-integration-ide/dist/ide/runtime.bundle.js`：`drawMap` 创建 `viewMode: '3D'`，但不读取 `skew`、不设置 pitch；`updateComponents` 不处理 `enableBuilding`，`tiltGesturesEnabled` 是空实现；`getMapProperties` 根据 `getViewMode_()` 返回 `is3d`。因此原版模拟器可报告支持 3D，却不应用小程序请求的俯仰角。AppX 属性表包含 `enable-building`、`enable-overlooking`、`skew`，这些原生属性继续供客户端使用。

本机模拟器 3D 补丁已因点击交互异常撤回，脚本 `scripts/simulator-map-3d.cjs` 已禁用生成和安装，仅保留恢复入口。原文件备份为安装目录下的 `modules.asar.path-seeker-3d-backup`。恢复需要管理员权限，恢复后必须完全退出并重启开发者工具；单元测试不代表模拟器交互通过验收。

```powershell
node apps/mp-alipay/scripts/simulator-map-3d.cjs restore 'C:/Program Files/小程序开发者工具/resources/app/modules.asar'
```

真机预览时进入行程并点击左侧 3D，检查镜头是否聚焦当前站点、`actualSkew` 是否大于 0，以及当前区域是否显示建筑侧面。若实际倾角为 0，仍属客户端未应用镜头；若倾角正常但没有建筑，需要继续核对客户端建筑图层支持及地图覆盖。构建和单元测试不证明真机建筑已渲染。若最终要求与 H5 完全一致，需要另行接入 H5 WebView 导览，并完成业务域名、鉴权和定位/音频交互配置。

导览页与 H5 保持三层结构：首次打开先显示语言选择层；选择语言后进入路线总览层，地图作为背景、路线卡片和“开始行程”作为主操作；正式开始后进入导航层，地图全屏展示，底部保留播放控制，站点正文、图片、视频、章节、讲解员和完成操作通过内容侧栏查看。导航层可收起内容回到地图，也可打开播放序列侧栏；返回总览不会结束服务端行程，结束行程才会清除进行中的导航状态。

导览支持：

- 中文、英语、俄语、西班牙语、法语、日语讲解；导览主要控制文案复用 H5 翻译，账号和问答界面使用中文。
- 原生地图显示路线、站点、目的地边界、景点多边形/圆形范围；支持位置跟随、路线显隐、缩放和地图全屏。隐藏路线仍保留范围轮廓。
- 正式行程中点击地图标记或站点列表会进入该站并播放；上一站/下一站只浏览并播放，不写行程进度。已完成站点重听不重复记账。
- 播放顺序为前置额外音频 → 讲解章节及段间媒体 → 节点视频 → 后置额外音频。额外音频随整站默认播放，内容面板隐藏额外音频列表和跳过开关，历史跳过偏好不再生效。支持暂停、继续、拖动、前后 15 秒和重播。
- 额外音频出错时提示并跳过；主讲解缺失或失败时保留正文和手动完成入口，不自动标记完成。
- 正式行程讲解完成后发送 `completionSource=2`；手动完成发送 `completionSource=1`。仅额外音频结束不会完成本站。
- 支持手动选择站点和近站讲解。开启底部播放台的近站开关后同时开启地图位置跟随；3D 镜头在跟随模式下优先使用有效定位。定位稳定接近景点后，显示 280 × 280rpx 的方形提示卡，有节点图片时显示图片。优先提示距离最近的未入队站点，可点卡片立即进入、点 ↻ 切换候选，或点“继续当前”取消。本张卡片显示 3 秒后自动收起并将该站加入讲解队列；重复定位不会重置倒计时。开启队列中的自动接续后，空闲时接播，当前讲解结束时接续播放。
- 手动浏览时暂缓自动切换。显式进入站点后恢复接续；播放队列按账号、路线与行程保存，恢复时对照服务端已完成站点。
- 入队表示等待播放，当前站的一整轮媒体结束后才自动完成并接续下一站：前置音频 → 章节及段间媒体 → 节点视频 → 后置音频。没有主讲解章节、仅有节点视频的正式站点，视频自然结束也可完成；跳过或视频错误不冒充完成。单独点击的视频或额外音频不完成本站，结束、跳过或出错后恢复它打断的主讲解和时间点。
- 自动接续要求正式行程仍在进行、导航层可播放、自动接续已开启、内容未锁定，并且没有主动暂停、手动浏览、问答/收音/转写、翻译房间占用或其他媒体播放。视频加载期间也视为占用。开启近站、返回页面、问答退出、翻译房间状态变化和成功操作结束时会重试已有队列；完成回调遇到忙碌或问答时保留到条件解除后处理。入站请求失败时保留队列并显示错误，不循环重试请求。
- 自动切站响应返回后重新检查提问、翻译房间、录音、前后台和自动播放偏好，受阻的声音保留为待播意图；条件恢复后只启动一次，不重复提交切站请求。加载中的视频同样保留提问恢复现场。
- 播放断点校验账号、行程、路线、站点、导游、语言和额外音频设置；最多恢复六小时内的匹配断点。
- 从导览进入“问一问”时携带当前路线、站点、导游、章节和播放时间；支持页内浮层及展开，问答结束/关闭后恢复被中断的讲解，用户主动暂停的音频不自动恢复。
- 导览页点击麦克风立即开启收音并打开问答弹层，内容页再次点击结束并识别发送；关闭问答或切文字模式会取消。

问答支持增量文字与按句接续音频、当前句字幕及播放进度、安全 Markdown 富文本、失败问题重试、历史与建议问题。朗读时点击麦克风会停止当前回答并转为录音；支持设备上可主动开启“说话打断”。本次六项业务补齐和实机验收步骤见 [H5 业务对齐验收单](../../docs/94-alipay-h5-business-parity.md)。

首次打开会先创建游客身份，并直接进入授权页面。用户同意隐私说明后，点击“手机号授权登录”，通过原生 `getAuthorize` 按钮授权手机号；客户端将 `my.getPhoneNumber` 的完整签名结果和 `my.getAuthCode` 的 `auth_user` 授权码提交到 `/AppUser/MiniProgramLogin`。服务端验签后按手机号关联已有 `app_user`，因此能识别后台已授予的车夫权限；没有匹配账号时才升级游客或创建账号，不读取支付宝昵称或头像。旧版无手机号的平台身份可关联到已有手机号账号，历史记录不会自动合并。游客及密码入口由 `src/config.js` 的 `authOptions` 控制。授权后进入语言选择和路线总览，并优先选中本机记住的已发布路线，否则选中当前语言的首条路线。检测到同一路线有进行中的行程时，恢复导航地图和播放状态。服务端配置、微信兼容接口和 DDL 见 [小程序身份接入说明](../../docs/93-mini-program-auth-integration.md)，上线前需执行数据库脚本并部署新接口。

讲解房间与 H5 使用相同的双语消息结构：每段一条消息，译文在前、原文在后，共用气泡。播放器预加载下一句，并在播放完成后清理临时音频；音频分片和进度回调不再反复刷新整段会话。需使用真机验证句间间隙、暂停恢复和长时间连续收听。

小程序页面参数支持：

```text
pages/tour/index?routeId=字符串路线ID&destinationId=字符串目的地ID&lang=zh
```

`routeId`、`destinationId` 与所有业务主键始终按字符串处理。地图 marker ID 使用站点下标加一，仅作为原生地图事件索引。

## 服务与开放平台配置

### 定位与近站判定

位置跟随以“上一次自动居中的定位”为基准，只有累计位移达到 5 米才更新地图中心；重复坐标、微小漂移以及仅方向或精度变化不会重新设置镜头，因此可以在位置未明显变化时拖动地图。定位标记和近站判断仍处理每次位置回调，不受镜头更新阈值影响。重新打开跟随会立即聚焦有效当前位置；重新开启近站讲解会在收到有效定位后首次聚焦。

`my.getLocation` 使用 `type: 0`、`cacheTimeout: 0` 请求新位置；一次请求结束后等待 3 秒再请求，避免重叠。页面显示平台返回的水平误差估计，不将显示值人为缩小。35 米属于可接受范围；误差超过 65 米、未知精度或位置超过 15 秒不参与近站判定。应在手机系统中给支付宝开启精确位置，并在支付宝中允许小程序定位；室内、高楼遮挡、节电模式会影响实际精度，频繁请求不能保证米级定位。

近站按当前路线中未完成、非当前行程站点筛选，使用统一的 WGS84 坐标计算：

- 有多边形范围：区域内距离为 0，区域外计算到边界的最短距离。
- 有圆形范围：距离为 `max(0, 到圆心距离 − 半径)`。
- 没有范围或范围几何不可用：回退为到景点锚点的两点距离；景点无坐标时使用路线节点坐标并按路线坐标系转换。两者都缺失则不触发。

默认进入阈值为 50 米（含边界）。景点范围的 `proximityDistanceMeters` 优先，其次是节点 `triggerRadiusMeters`，再是景点范围的 `defaultProximityDistanceMeters`，最后是全局 50 米。候选集合需稳定至少 1.5 秒；由于轮询间隔为 3 秒，通常在下一次定位回调后确认，再展示 3 秒提示卡。倒计时结束前重新核验位置、范围、账号、路线和行程；切换站点、打开内容/队列/问答、离开页面或定位失败会取消待确认卡片。后台模式继续保留原有稳定近站入队行为，不显示卡片；系统挂起定位时无法保证后台更新。

`src/config.js` 默认配置：

```text
API: https://www.omahaaigc.com/path-seeker/api
默认问答音色: male-qn-qingse
```

## 平台差异

- **问答接收方式**：请求启用分块并探测 `onChunkReceived`。实际收到分块时增量解析 UTF-8/SSE、更新文字，每句音频收齐后写临时文件并接续播放；完整响应不重复播放已消费事件。客户端不提供分块或中间链路缓冲时，自动按完整响应处理。是否能稳定边生成边播放需要真机确认，当前没有引入 WebSocket。单次问答/转写超时为 120 秒；取消后服务端可能已保存答案，可通过历史查看。
- **录音**：使用 `my.getRecorderManager()` 生成单声道 16 kHz WAV。导航点击即开启并打开问答，内容页再次点击结束，转写成功自动提交；录满60秒自动结束。启动期间显示等待，原生启动成功后展示连续波浪动效；波浪表示收音状态，不表示实际音量。关闭问答、切文字或切后台取消；弹层展开收起不中断。WAV 需要支付宝 **10.6.36 或以上**。临时文件使用 `audio/wav` 的 multipart 上传，保留 WAV 二进制数据；该上传链路需要真机联调确认。模拟器不能代替录音验收。
- **麦克风权限**：点击麦克风后仍由原生录音接口发起首次权限请求。录音返回权限拒绝（错误码10）时，结束本轮录音并主动调用 `my.showAuthGuide({ authType: 'MICROPHONE' })`；不支持、调用失败或未显示引导时，提示到手机系统设置中允许支付宝使用麦克风。引导完成不代表已授权，返回后需再次点击麦克风重试。已取消、已销毁的录音和其他错误不会自动弹出权限引导；问答及隐私页的管理麦克风入口复用相同处理。
- **说话打断**：默认关闭，仅在提供实时录音帧回调的设备显示开关。开启后使用本机 PCM 能量检测，不上传检测帧；结束后清理原生接口产生的临时文件。PCM 帧格式、录放并行与外放回声效果需要实测，不支持时点击麦克风打断。
- **正文朗读回退**：本次按“已上架路线一定有音频”交付，不移植 H5 浏览器语音合成兜底。保留音频加载失败后的正文和手动完成入口。
- **前后台**：`config.background` 默认开启。开启时切换页面或息屏不暂停讲解，导览页继续轮询定位；后台播放依赖 `app.json` 的 `requiredBackgroundModes: ["audio"]` 与 `InnerAudioContext.supportBackgroundPlay`，息屏后能否持续由支付宝客户端决定，需要真机确认。支付宝没有后台定位 API，息屏后 `my.getLocation` 可能被系统挂起，定位只保证应用内切页时继续。关闭该开关后恢复“离开导览页暂停讲解并停止定位”。离开问答页仍会停止录音、取消等待、停止问答音频并清理临时文件。
- **坐标**：原生地图与定位使用 GCJ-02；地理范围判定转换为 WGS84 后复用共享逻辑。地图显示也会按后端坐标标识转换。
- **本人位置与刷新**：开启近站定位并取得坐标后，地图显示蓝绿色本人位置点和“我的位置”标签，首次定位居中，后续仅更新标记；开启跟随后镜头持续跟随。关闭定位或拒绝权限会移除本人标记。定位立即请求一次，每次请求结束后等待 3 秒再请求，因此实际更新间隔是“定位请求耗时 + 3 秒”。H5 使用浏览器 `watchPosition` 持续接收更新，由系统与浏览器决定频率，没有固定秒数。
- **近站讲解与定位质量**：底部“开启附近讲解”同时开启定位和自动接续；关闭时关闭两项。队列内仍可单独关闭自动接续，保留附近提示。播放栏展示定位精度或定位失败原因；无效经纬度不更新位置，缺失/无效精度按未知处理。附近判定要求精度不超过 65 米、位置不超过 15 秒，并连续稳定至少 1.5 秒；默认接近距离为 50 米，站点或景点范围配置可覆盖。已有讲解播放时附近站点按距离入队，播完再接续；手动浏览、内容锁定、手动暂停、问答和翻译房间占用时不会自动切换。这里只能显示系统返回的位置精度，不能测量卫星信号强度。
- **历史范围**：后端目前没有户外 `RouteVisit` 历史列表接口。本机漫游记录按账号保存最多 100 条；服务端活动行程可在对应路线恢复。`Gameplay` 历史来自已有探索接口，不代表完整的跨设备户外历史。

## 验收

自动测试覆盖登录续期与账号竞争、字符串长 ID、流式 UTF-8/SSE、按句音频、旧请求隔离、录音交接与自动发送、人声检测、浮层生命周期、浏览与行程完成隔离、断点恢复、地图跟随、语言切换、近站稳定判定、队列去重与接续、内容锁定和手动选站播放和各类历史返回。测试使用隔离的 `my.*` 模拟环境，不证明原生客户端或线上后端已经联调成功。

开发者工具与真机按以下顺序验收：

1. 编译六个页面，检查冷启动游客目录、空数据、网络错误重试与三个原生 Tab。
2. 搜索路线、切换目的地/讲解语言/导游，检查多语言路线、地图标记与范围、站点正文、图片和视频。
3. 正式行程中点击地图/列表站点，确认开始事件正确；上一站/下一站浏览并播放时不写 `UpdateStop`，检查前置/章节/后置音频顺序以及自动、手动完成来源。
4. 在不同音频段暂停、拖动、切到问答并返回、切到后台、退出重新进入，检查断点位置和重复额外音频行为。
5. 真机开启近站讲解，检查当前位置、精度不足和拒绝授权提示；稳定靠近景点时加入队列且重复定位不重复入队。分别关闭/开启自动接续、内容跟随，验证当前讲解不被打断、队列接续与手动跳过；关闭近站后停止新增候选，手动选站仍可播放。
6. 创建对话、查看历史、删除对话、文字问答、语音回复、来源图片和位置导航；停止等待后再看历史。
7. 真机点击收音至少一秒，再次点击结束，检查导航立即弹出问答、波浪动效、WAV 转写后自动提问；测试启动中再次点击取消、关闭问答、切文字、拒绝麦克风权限、切后台、60秒自动结束与朗读期间点击打断。另按验收单记录分块接收、首句播放时机和外放回声效果。
8. 注册/登录、资料修改、游客与正式账号切换，确认历史、断点、音色及排队信息按账号隔离；清除本机记录后服务端进度仍可恢复。
