# 管理端适配设计

## 信息架构

保留现有管理端入口，不新增“黄包车”页面：

| 现有能力 | 兼容后的含义 | 户外扩展 |
| --- | --- | --- |
| 博物馆 | 目的地 | `sceneType` 区分场馆与户外区域 |
| 楼层 / 展厅 | 场景空间 | 户外使用文化点和地理坐标 |
| 展品讲解 | 文化内容 | 一个文化点关联多个导游讲解版本 |
| 主题路线 | 游览路线 | 停靠点、线路几何、里程、接驳方式 |
| 审核上架 | 发布工作流 | 室内外完全复用 |

## 建议后端字段

- 目的地：`venueType`、`coordinateSystem`、`mapProvider`（与 C 端一致使用 `Amap`）、`boundaryGeoJson`、地图中心点。
- 文化点：`destinationId`、经纬度、类型、地址、建议停留时间、发布状态。
- 讲解版本：`placeId`、`guideId`、风格、讲解词、音频、时长、审核状态。
- 路线：`sceneType`、`geometryGeoJson`、里程、预计时长。
- 路线节点：`placeId`、顺序、抵达说明、交通方式、停留时长。

## 工作流

运营先创建目的地，再维护场景内容；路线只引用同一目的地下的文化点或展厅节点。路线保存后继续走现有“草稿 → 提交审核 → 审核通过并上架”，从而避免为黄包车项目复制权限、审核和发布逻辑。

## 讲解站点（节点）内容

C 端站点讲解已从“一条文稿 + 一条音频”升级为分段讲解，管理端节点内容编辑按同一结构维护：

| 字段 | 含义 | C 端表现 |
| --- | --- | --- |
| `name` / `category` | 站点名称与器物类别 | 站点标题与类别标签 |
| `segments[]` | 解说词段落（标题 + 正文）；Demo 每站维护一段，模型保留分段能力 | 逐段切换的讲解章节 |
| `segments[].audioUrl` / `durationSeconds` | 逐段音频与时长 | 按段落顺序连续播放 |
| `audioStatus` / `audioDurationSeconds` | 整站音频生成状态与总时长 | 播放器可用状态与总时长 |
| `guideId` / `guideName` / `guideStyle` | 站点导游与讲解风格 | 站点署名与风格说明 |
| `pronunciations[]` | 关联多音字（词语 + 标准拼音） | 人名、地名与专业词汇读音 |
| `images[]` | 配图（上传 / AI 生成） | 站点封面与图集 |
| `videoUrl` | 选填视频 | 站点内的观展短片入口 |

交互与 C 端保持一致：节点画布单击预览、**双击打开节点内容编辑弹窗**；弹窗内可维护站点名称、解说词、导游、音频（刷新 / 生成 / 试听）、多音字与配图，保存后写回演示数据并即时反映到手机预览。弹窗始终只编辑被双击的那一个站点，不带出同路线其它站点的内容。

户外路线与室内共用同一套站点内容模型与编辑弹窗：户外站点通过 `placeId` 绑定文化点，因此路线列表、地图与手机预览三处都能直接进入站点编辑（双击地图站点、点击“编辑这一站”或站点列表的编辑入口），内容无需重复维护。

## 内容多语言

语言是**路线自身的属性**：一条路线只承载一种语言的内容，同一条线路的其它语言是各自独立的路线记录。B 端只对**内容**多语言，界面与操作文案保持中文。

| 维度 | 说明 |
| --- | --- |
| `TourRoute.locale` | 路线语言（`zh` / `en` / `ru` / `es`），路线的名称、主题、停靠点抵达说明都用该语言编写 |
| 关联方式 | 中文是**源版本**（沿用原 `id` 与编码），其它语言形如 `490000000000000001-en` / `HH-R-01-EN`；`src/domain/content.ts` 的 `siblingRoutes` 按源版本 id 聚合同线路语言版本 |
| `ArtifactStage.locale` | 站点内容语言与所属路线一致；`translationOf` 指向同线路的中文源站点，便于对照维护 |
| 音频 | 中文路线产出 TTS 音频（可刷新 / 生成 / 试听）；其它语言 `audioStatus: 'none'`，C 端用系统语音朗读 |
| 共用字段 | 配图、视频、多音字与站点结构不区分语言；多音字只作用于中文音频合成 |

- 列表：主题路线页提供「全部语言 / 中文 / English / Русский / Español」下拉筛选；每行显示该路线语言标记，以及同线路已创建的语言版本。
- 工作台：头部展示同线路的语言版本，可直接切换到另一语言版本继续编辑；站点内容弹窗只编辑当前路线的语言版本。
- 新增语言版本：为同一条线路新建一条目标语言的路线（编码加语言后缀），复用相同停靠点与文化点，再逐站补译文。入口有两个：列表行「更多操作 · 多语言转换」（方向固定为中文源 → 其他语言，默认勾选尚未创建的语言，已有同语言译文的站点直接复用、其余标记译文待补），以及「新增主题路线」弹窗里的路线语言选择（默认中文，选择其它语言时同时创建中文源版本）。

## 底图与坐标系

- 底图与 C 端统一使用高德（AMap），Key 与安全配置走 `.env.local`，加载失败时降级为提示层，不影响路线与站点编辑。
- 业务数据继续以 WGS84 存储，绘制前统一经 `src/domain/coordinates.ts` 转为 GCJ02，避免底图与实际位置偏移。

## 审核与发布兼容

站点内容与路线状态解耦：站点可单独处于“音频待生成 / 生成中 / 已生成”，整条路线仍走原有“草稿 → 提交审核 → 审核通过并上架”流程，避免节点内容缺失的路线直接上架。
