# 后海管理端兼容 Demo

一个独立的 Vue 3 + TypeScript 管理端 Demo，用现有“目的地管理、游览路线、地图、审核上架”结构同时承载场馆探索和户外黄包车漫游。

## 运行

```bash
npm install
npm run dev
```

访问 `http://127.0.0.1:5190/`。

```bash
npm run typecheck
npm test
npm run build
```

## 已实现

- 完整保留线上 8 项菜单、菜单顺序、名称和原有页面层级，只在“博物馆”现有列表中兼容“场馆探索 / 户外漫游”数据。
- 运营分析、博物馆、馆藏内容、展厅地图、导游管理、主题路线、发音词典和用户管理均可进入，并提供对应的 Mock 列表、搜索、筛选和操作反馈。
- 后海户外工作台包含真实地图、5 个真实文化点、坐标、服务边界和多导游讲解版本。
- 游览路线页统一展示室内与户外路线，并复用草稿、审核、上架状态。
- 文物路线继续使用节点画布、手机讲解预览和对话编辑三栏工作区；只有户外漫游路线进入真实地图与停靠点编辑器。
- “展厅地图”复用现有工程的三级选择器、点位画布、右侧详情、取点、撤销和缩放结构；室内显示展厅平面图，选择户外博物馆时在同一工作区显示真实地图。
- 户外路线编辑器支持真实地图线路、停靠顺序、黄包车/步行接驳、抵达说明和停留时长。
- 场馆工作台继续使用楼层、展厅和设施结构；室内路线继续使用展厅节点。
- 所有业务 ID 按字符串传递，避免 `int64` / 雪花 ID 精度损失。

## 地图配置

默认使用 OpenStreetMap 公开瓦片。复制 `.env.example` 为 `.env` 可替换瓦片地址。生产环境若使用腾讯地图，将浏览 Key 配到 `VITE_TENCENT_MAP_KEY`，并在接入层完成 WGS84 / GCJ02 转换。

本项目只使用本地 Mock 状态，不会请求或修改现有管理端接口。
