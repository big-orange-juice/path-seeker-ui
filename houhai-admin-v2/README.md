# 后海管理端兼容 Demo

一个独立的 Vue 3 + TypeScript 管理端 Demo，用现有“目的地管理、游览路线、地图、审核上架”结构同时承载场馆探索和户外黄包车漫游。

## 运行

```bash
npm install
npm run dev
```

访问 `http://127.0.0.1:5190/`。

```bash
npm run typecheck
npm test
npm run build
```

## 已实现

- 完整保留线上 8 项菜单、菜单顺序、名称和原有页面层级，只在“博物馆”现有列表中兼容“场馆探索 / 户外漫游”数据。
- 馆藏内容页提供新增 / 编辑弹窗（参照正式项目：基础信息、分类、展陈归属、主图与「更多资料」折叠区），保存与删除写回演示数据，列表支持关键字 / 分类 / 状态筛选。
- 后海户外工作台包含真实地图、5 个真实文化点、坐标、服务边界和多导游讲解版本。
- 游览路线页统一展示室内与户外路线，并复用草稿、审核、上架状态。
- 「新增路线」与正式版一致弹出「新增主题路线」对话弹窗：左侧用一句话主题生成路线，右侧「生成结果」实时展示当前路线、站点生成进度与关联文物；弹窗内可选路线语言（默认中文，其它语言同时创建中文源版本），演示数据里按提示词挑选目的地、关联文物与站点，生成完成后路线与站点内容以草稿写入演示数据（`src/domain/routeChat.ts`），可在列表中继续编辑或提交审核。
- 列表「更多操作」提供「多语言转换」弹窗：转换方向固定为**中文源 → 其他语言版本**，默认勾选尚未创建的语言，转换时复用中文源的停靠点与文化点，已有同语言演示译文的站点直接复用，其余站点标记「译文待补」并指向中文源站点；生成的版本为草稿，走原有审核上架流程。
- 多语言按「**一条路线一种语言**」维护：同一条线路的不同语言是各自独立的路线记录（中文为源版本，其它语言编码加 `-EN` / `-RU` / `-ES` 后缀），列表提供「全部语言 / 中文 / English / Русский / Español」下拉筛选，每行显示本行语言、同线路已创建的语言版本以及对应的中文源版本；站点内容语言跟随路线，工作台头部可直接切换到同线路的其它语言版本，中文路线产出 TTS 音频、其它语言由 C 端系统语音朗读。
- 文物路线继续使用节点画布、手机讲解预览和对话编辑三栏工作区；只有户外漫游路线进入真实地图与停靠点编辑器。
- 文物站点改为数据驱动：节点画布直接展示音频状态、分段数、配图数与多音字条数，**单击节点预览、双击节点打开内容编辑**，中间的手机预览同步播放分段讲解。
- 节点内容编辑弹窗对齐 C 端站点讲解：站点名称、解说词与音频、导游选择、音频生成状态与试听、关联多音字、配图（上传 / AI 生成）以及待生成的视频地址；保存后写回演示数据并同步到 C 端预览。
- “展厅地图”复用现有工程的三级选择器、点位画布、右侧详情、取点、撤销和缩放结构；室内显示展厅平面图，选择户外博物馆时在同一工作区显示真实地图。
- 户外路线编辑器支持高德地图线路、停靠顺序、黄包车/步行接驳、抵达说明和停留时长。
- 户外站点与室内站点一致支持内容编辑：单击站点预览，双击地图站点或点击“编辑这一站”打开弹窗，维护解说词、导游、音频、多音字与配图；弹窗只编辑被双击的那一个站点，每个站点维护一段解说词（模型保留分段能力，可继续新增段落）。
- 中间手机预览与当前 C 端行程页一一对应：顶部 `返回地图 / 路线名 / 结束行程`，3D 高德地图（俯仰视角、蓝色导航线并聚焦当前站点，与 C 端行程态一致），左侧路线工具条，左下讲解悬浮条（播放暂停 + `查看内容` + 站点名 + `2 / 5`），底部定位条；点开讲解面板后与 C 端结构一致（站点胶囊切换停靠点、封面配图、`播放讲解`、讲解正文、`展开介绍 / 观看视频`、`接下来看`）。C 端行程页没有途经点抽屉，这里同样不额外添加。
- 场馆工作台继续使用楼层、展厅和设施结构；室内路线继续使用展厅节点。
- 所有业务 ID 按字符串传递，避免 `int64` / 雪花 ID 精度损失。

## 地图配置

管理端底图与 C 端保持一致，统一使用高德（AMap）。复制 `.env.example` 为 `.env.local`，填入高德 Web JS Key 与安全配置：

```text
VITE_AMAP_KEY=你的高德 Web JS Key
VITE_AMAP_SECURITY_CODE=安全密钥（二选一）
VITE_AMAP_SECURITY_PROXY=代理地址（二选一，生产环境推荐）
```

未配置 Key 或加载失败时，地图区域会给出提示而不影响其它功能。业务数据仍以 WGS84 存储，绘制前统一转换为 GCJ02（`src/domain/coordinates.ts`）。Key 的域名白名单需包含本地开发地址。

首个加载的版本为高德 2.1Beta，失败时自动回退 2.0。

本项目只使用本地 Mock 状态，不会请求或修改现有管理端接口。

## 演示数据说明

- 讲解站点保存在 `src/data/mock.ts` 的 `stages` 中，字段与 C 端站点讲解一一对应：`segments`（解说词与音频，当前每站一段）、`pronunciations`（多音字）、`images`（配图）、`videoUrl`（选填视频）、`placeId`（户外站点对应的文化点）、`locale`（内容语言，跟随所属路线）。
- 室内文物站点按路线维护；户外站点按“路线 × 停靠点”生成，内容种子写在 `outdoorStageSeeds`，音频直接复用 C 端黄包车讲解的同一批素材。
- 音频地址以 `demo:` 开头表示由浏览器本地合成的演示音频，时长与文稿一致，不发起网络请求；其余为示例远端地址。
- 配图使用内联 SVG 占位图，保证离线也能看到配图、封面与缩略图效果。
